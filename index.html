ASIR Battle

Configura la partida, activa los paquetes que quieras usar e importa ejercicios desde JSON. La pantalla está adaptada para móvil y se puede desplazar completa.

Importar ejercicios JSON
Opción 1: selecciona un archivo .json de tu ordenador. Opción 2: pega el JSON en el cuadro de texto. Cada importación se guardará como un paquete que podrás activar, desactivar, renombrar, etiquetar por asignatura o borrar.

Ver estructura JSON válida para generar ejercicios con IA
Instrucción sugerida para una IA:
Genera un array JSON válido para este juego. Cada objeto debe usar uno de estos tipos: xml, html, css, sql, sqlpuzzle o test. Devuelve solo JSON, sin Markdown.
